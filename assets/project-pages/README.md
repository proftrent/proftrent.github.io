# Project page assets

This directory contains production JavaScript and page-specific CSS used by visitor-facing pages in `work/`.

- Each project keeps its content and behavior in a folder matching the page slug.
- `shared/case-study-tabs.css` contains the shared tabbed case-study layout.
- Experimental layouts and design studies remain in `prototypes/`.

When editing tabbed project-page copy, use the JavaScript file inside that project's folder.
