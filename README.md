# ProfTrent Website

A responsive, accessible static portfolio for Trent Hoy, organized around learning product leadership.

## Pages

- `index.html` — personal positioning, featured work, impact, and the visual workbench
- `projects.html` — seven case-study-style projects
- `how-i-build.html` — end-to-end process, technical breadth, AI, and operational capability
- `about.html` — professional story, design ethos, and personal context
- `contact.html` — résumé and contact details

`innovation.html`, `leadership.html`, and `portfolio.html` preserve old links by forwarding visitors to the new structure.
